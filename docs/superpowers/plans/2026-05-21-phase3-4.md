# CareerPilot Phase 3-4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade CareerPilot from Phase 1-2 into a real RAG-enabled, deployable application with vector retrieval, company knowledge, output provenance/version comparison, CI, security hardening, and production-oriented docs.

**Architecture:** Keep the existing FastAPI + LangGraph + React/Vite monorepo and extend it around a pgvector-backed knowledge layer. Phase 3 adds chunked knowledge ingestion, retrieval, provenance, company knowledge, and historical output comparison; Phase 4 turns the project into a demonstrable engineering deliverable with hardened config, Docker Compose, CI, docs, and verification.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, PostgreSQL + pgvector, Redis, Celery, LangGraph, React, Vite, Vitest, Pytest, GitHub Actions, Docker Compose.
